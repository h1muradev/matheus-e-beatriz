# Matheus ♡ Beatriz

Um cantinho romântico feito para a Beatriz, com fotos, vídeos, declarações e a música **Amor**, de Emmanuel Cortes.

A experiência começa ao tocar em “entrar no meu coração”. Um coração animado revela a história e a música é reproduzida pelo YouTube em segundo plano, sem exibir o player na página.
